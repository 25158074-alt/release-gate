# Release Gate

Static submission package:

- `index.html` — package landing page
- `submission/index.html` — submission hub
- `submission/pitch-deck.html` — browser pitch deck
- `demo/root-cause-race.html` — interactive visual dashboard
- `submission/*.md` — project brief, architecture, setup, demo script, and impact metrics

## Run locally

Serve the repository with any static web server, for example:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.
